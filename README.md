# JP Stock Screener

日本株のテクニカル指標を毎営業日自動取得・計算し、静的ダッシュボードで閲覧できる個人用スクリーニングシステム。外部の有料APIは使わず、GitHub Actions の Cron と GitHub Pages のみで完結します。

## 構成

| ファイル | 役割 |
|---|---|
| `.github/workflows/update_data.yml` | 平日 11:30 JST（前場引け）に自動実行される GitHub Actions ワークフロー |
| `src/fetch_universe.py` | JPX公式の上場銘柄一覧から東証プライム全銘柄を取得し `data/universe_prime.json` に保存（7日以上古い場合のみ再取得） |
| `src/update_stocks.py` | 東証プライム全銘柄の株価（過去約2年分）を一括取得・分析し、最も総合スコアが強い「買い」候補・「売り」候補 上位10銘柄ずつ（最大20銘柄）に絞り込んで `data/stocks.json` に保存 |
| `src/index.html` | Tailwind CSS (CDN) + バニラJS のビルド不要ダッシュボード（モバイル優先のカード型UI、ダークモード） |
| `data/universe_prime.json` | 東証プライム全銘柄リスト（キャッシュ、`fetch_universe.py` が自動更新） |
| `data/stocks.json` | 計算済みデータ（Actions が自動更新） |

## セットアップ

1. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、ブランチをメインブランチ（フォルダは `/ (root)`）に設定
2. **Actions** タブから `Update Stock Data` ワークフローを手動実行（workflow_dispatch）して初回データを生成
3. `https://<ユーザー名>.github.io/<リポジトリ名>/src/` にアクセス

以降は平日 11:30 JST に自動でデータが更新されます。

## 対象銘柄（東証プライム全銘柄）

対象銘柄は `fetch_universe.py` が JPX公式サイトの上場銘柄一覧（Excel）から東証プライム市場に絞り込んで自動生成します（`data/universe_prime.json`、約1,600銘柄、キャッシュは7日ごとに再取得）。このファイルが存在しない・取得に失敗した場合は、`src/update_stocks.py` 内の `FALLBACK_STOCKS`（動作確認用の主要44銘柄）にフォールバックします。

JPX側のファイル形式や配布URLが変更された場合、`fetch_universe.py` の `JPX_LISTED_ISSUES_URL` を最新のものに更新してください。取得に失敗しても既存のキャッシュ・フォールバックがあるため、日次の株価更新自体は止まりません。

`data/universe_prime.json` のスキーマ（保存するフィールド）を変更した場合は `fetch_universe.py` の `SCHEMA_VERSION` を1つ上げてください。日数だけでキャッシュの鮮度を判定すると、スキーマ変更前に生成された古い形式のキャッシュがそのまま使われ続けてしまうため（例: セクター列を追加した際に実際に起きた不具合）、schema_version が一致しない場合は日数に関わらず強制的に再取得します。

株価は Yahoo Finance のレート制限を避けるため `CHUNK_SIZE`（既定150銘柄）ずつまとめて取得します。約1,600銘柄を毎日処理する都合上、ワークフローのタイムアウトは30分に設定しています。

手動で銘柄を追加・固定したい場合は `src/update_stocks.py` の `FALLBACK_STOCKS` 配列に1行追加してください（`data/universe_prime.json` が存在する間は使われません）。

```python
{"code": "XXXX.T", "name": "銘柄名", "market": "市場名", "sector": "33業種区分"},
```

## 内部で使用しているテクニカル指標

以下をすべて内部で計算し、単一の「見通し」スコアに合成します（ダッシュボードには個々の生データではなく合成結果を簡潔に表示）。

- RSI (14日, Wilder 平滑化)
- MACD ヒストグラム
- 移動平均トレンド（25日線・75日線の位置関係）
- ボリンジャーバンド %B（20日, ±2σ）
- 出来高急増（20日平均比 + 当日の値動き方向）
- ストキャスティクス %K（14日, 3日平滑化）

**総合スコア（-6〜+6）**: 上記6指標をそれぞれ強気(+1)/弱気(-1)/中立(0)で判定し合算した客観的な数値。スコアが正の銘柄を「買い」候補、負の銘柄を「売り」候補として扱う。

**統計的上昇確率（参考）**: 同一銘柄の過去約2年間で、現在と同じ総合スコアのバケットが発生した際に5営業日後の株価が上昇していた頻度（%）。該当件数（サンプル数 n）が5件未満の場合は非表示。

**理由の要約**: RSI・MACD・移動平均トレンド・ボリンジャーバンド・出来高・ストキャスティクスのうち、実際にスコアに寄与した指標を「RSIが27.9と売られすぎ水準」のような客観的な短文リストにして各銘柄に添付（`build_reasons()`）。

**上位20銘柄への絞り込み**: 東証プライム全銘柄をスキャンした上で、総合スコアが強い「買い」候補・「売り」候補をそれぞれ上位10銘柄（同点の場合は統計的上昇確率が50%からより離れている方を優先）に絞り込み、`data/stocks.json` に保存する（`select_top_candidates()`）。スキャン自体は毎回全銘柄が対象（そうしないと「上位」を発見できないため）だが、保存・表示するのは絞り込み後の最大20銘柄のみとすることで、スマートフォンでの読み込み・一覧性を優先している。

## ダッシュボードの機能（モバイル優先）

- 1銘柄1カードの縦並びレイアウトで、スマートフォンでの閲覧に最適化（横スクロール不要）
- カード上部に「買い」「売り」を大きな色分けバッジで表示し、一目で判別可能
- カードには理由の要約（テクニカル的な根拠）を箇条書きで表示し、細かい指標は既定で非表示
- 「すべて／買い／売り」のタブで即座に絞り込み可能
- 「詳細データを見る」を開くと RSI・25日乖離率・総合スコア・統計的上昇確率・TradingViewへのリンクを表示
